# Profile template

Write `<workspace>/profile.md` with exactly these sections, filled from the CV and the interview. It is the candidate side of every score. About one page. Be specific: real tool names, real verticals, real numbers. Tag skills honestly; a skill mentioned once in the CV is `Exposure`, not `Strong`.
